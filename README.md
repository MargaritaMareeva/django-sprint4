# Блогикум


**Блогикум** — это учебный проект, блог-платформа на Django для публикации личных дневников.

Пользователи могут публиковать посты, комментировать, добавлять изображения, управлять профилем и взаимодействовать с контентом.

Реализованы отложенные публикации, права доступа, пагинация, кастомные страницы ошибок.


---
### ФУНКЦИОНАЛЬНОСТЬ
---
- Управление аккаунтом: регистрация, авторизация и настройка личного профиля.
- Работа с постами: создание, редактирование, удаление и прикрепление изображений (доступно авторизованным пользователям).
- Социальное взаимодействие: система комментариев, где изменять или удалять свои комментарии может только их автор.
- Продвинутый контент: поддержка отложенной публикации постов, а также привязка к категориям и местоположениям.
- Администрирование: удобная панель управления для модерации категорий, локаций и пользователей.
- Надежность: кастомные страницы ошибок для кодов 403 (CSRF), 404 и 500.

### УСТАНОВКА И ЗАПУСК
---

**1. Клонировать репозиторий и перейти в него в командной строке:**
```bash
git clone https://github.com/MargaritaMareeva/django-sprint4.git
```
```bash
cd django-sprint4
```
**2. Создать и активировать виртуальное окружение:**
```bash
python3 -m venv venv
```
- Для Windows:
```bash
venv\Scripts\activate
```
- Для Linux/MacOS:
```bash
source venv/bin/activate
```
**3. Обновите пакетный менеджер:**
```bash
python -m pip install --upgrade pip
```
**4. Установить зависимости из файла requirements.txt:**
```bash
pip install -r requirements.txt
```
**5. Выполнить миграции:**
```bash
python manage.py migrate
```
**6. Создать суперпользователя (для доступа к административной панели):**
```bash
python manage.py createsuperuser
```
**7. Запустить проект:**
```bash
python manage.py runserver
```
Проект будет доступен по адресу: http://127.0.0.1:8000/

**АДМИНИСТРАТИВНАЯ ПАНЕЛЬ**

Для доступа к административной панели перейдите по адресу:
http://127.0.0.1:8000/admin/

Используйте данные суперпользователя, созданного на этапе установки.

В репозитории проекта есть файл с дампом базы данных: db.json.
Дамп содержит несколько постов; вы можете загрузить его в базу и посмотреть, как выглядит и работает наполненный сайт.

### Загрузить данные из файла db.json в базу данных:
- Для Windows:
```bash
python manage.py loaddata ../db.json
```
- Для Linux/MacOS:
```bash
python3 manage.py loaddata ../db.json
```
